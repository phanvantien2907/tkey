# Skill: macos-imk-shell

## When to Use

Activate this skill when:
- Creating the Swift macOS Input Method bundle for the first time
- Adding a new key-handling or composition feature to the Swift shell
- Debugging IMK issues (marked text, secure input, reload)

---

## Prerequisites

- `crates/core-ffi` exists and produces a `.a` static library. See `core-ffi-boundary` skill.
- Xcode installed, macOS 13+.
- The static lib path: `target/release/libtkey_core_ffi.a`

## Step 2 – Info.plist Keys

These keys are **mandatory** for the OS to recognise the input method:

```xml
<key>InputMethodConnectionName</key>
<string>TKey</string>

<key>InputMethodServerControllerClass</key>
<string>TKeyInputController</string>

<key>tsInputModeListKey</key>
<dict>
  <key>com.example.inputmethod.TKey.Vietnamese</key>
  <dict>
    <key>TISInputSourceID</key>
    <string>com.example.inputmethod.TKey.Vietnamese</string>
    <key>TISVisibleName</key>
    <string>TKey Vietnamese</string>
  </dict>
</dict>

<!-- Bundle type required by IMKit -->
<key>CFBundlePackageType</key>
<string>APPL</string>
```

## Step 3 – IMKServer Setup

```swift
// TKeyInputMethod.swift
import Cocoa
import InputMethodKit

@main
struct TKeyInputMethod {
    static func main() {
        let connectionName = Bundle.main.infoDictionary?["InputMethodConnectionName"] as! String
        guard let server = IMKServer(name: connectionName, bundleIdentifier: Bundle.main.bundleIdentifier) else {
            print("Failed to create IMKServer")
            exit(1)
        }
        _ = server // keep alive
        NSApplication.shared.run()
    }
}
```

## Step 4 – IMKInputController

```swift
// TKeyInputController.swift
import InputMethodKit

class TKeyInputController: IMKInputController {

    private var engine: OpaquePointer? = tkey_engine_create()

    override func handle(_ event: NSEvent!, client sender: Any!) -> Bool {
        guard event.type == .keyDown,
              let chars = event.characters,
              let first = chars.unicodeScalars.first else { return false }

        // SAFETY: engine is non-nil, created in init
        let key = Int8(bitPattern: UInt8(first.value & 0x7F))
        guard let resultPtr = tkey_process_key(engine, key) else { return false }
        defer { tkey_free_string(resultPtr) }

        let result = String(cString: resultPtr)
        if result.isEmpty { return false }

        (sender as? IMKTextInput)?.insertText(result, replacementRange: NSRange(location: NSNotFound, length: 0))
        return true
    }

    deinit {
        tkey_engine_destroy(engine)
    }
}
```

## Step 5 – Bundle & Install

```bash
# Build the static lib
cargo build --release -p tkey-core-ffi

# Copy into Xcode project (or use a build phase script)
cp target/release/libtkey_core_ffi.a platforms/macos-imk/

# Build Xcode project
xcodebuild -project platforms/macos-imk/TKeyInputMethod.xcodeproj \
           -scheme TKeyInputMethod \
           -configuration Release \
           CONFIGURATION_BUILD_DIR=build/

# Install to ~/Library/Input Methods/
cp -r build/TKeyInputMethod.app ~/Library/Input\ Methods/
```

---

## Step 6 – Ad-hoc Code Signing

```bash
codesign --force --deep --sign - ~/Library/Input\ Methods/TKeyInputMethod.app
```

For development only. For distribution: use a Developer ID certificate.

---

## Step 7 – Enable in System Settings

1. Open **System Settings → Keyboard → Input Sources**.
2. Click `+`, search "TKey", add it.
3. If TKey doesn't appear: kill and restart `TIMLaunchAgentUserSession`:
   ```bash
   pkill -f TIMLaunchAgentUserSession
   ```

---

## Step 8 – Reload After Rebuild

```bash
# Full reload cycle
pkill TKeyInputMethod 2>/dev/null
cp -r build/TKeyInputMethod.app ~/Library/Input\ Methods/
codesign --force --deep --sign - ~/Library/Input\ Methods/TKeyInputMethod.app
# macOS will auto-restart the input method agent
```

## Debugging

- **Console.app**: filter by process `TKeyInputMethod` for logs.
- **Secure input fields**: IMK cannot receive events in password fields — this is expected OS behaviour.
- **Marked text (preedit)**: use `setMarkedText(_:selectionRange:replacementRange:)` on the client. If marked text doesn't show in an app, check if the app supports NSTextInputClient.
- **Multiple instances**: only one IMKServer per process. If the app crashes on start, check `InputMethodConnectionName` matches exactly.

## Known Pitfalls

| Pitfall | Fix |
|---------|-----|
| Input method not in list | Check `tsInputModeListKey` in Info.plist |
| Crashes on key event | Check `catch_unwind` in Rust FFI |
| Preedit not visible | App may not implement NSTextInputClient (e.g. Electron — use `insertText` instead) |
| Secure input (password) | Expected — handle `IMKInputControllerDidDeactivate` gracefully |
| Bundle not reloaded | Run the full reload cycle above |

- [ ] `Info.plist` has all 4 required keys
- [ ] Input method appears in System Settings → Keyboard

- [ ] `tkey_engine_destroy` called on `deinit` (no leak in Instruments)
